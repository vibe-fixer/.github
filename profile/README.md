# VibeFix

VibeFix is an AI agent that fixes broken apps and Shopify stores in your code, then re-checks the live site.

- Free check of your live app or Shopify store: https://vibe-fixer.com
- Guides to common errors in apps built with AI builders and Supabase: https://vibe-fixer.com/guides
- Shopify store accessibility: https://vibe-fixer.com/stores
- YouTube: https://www.youtube.com/@Vibe-Fixer
